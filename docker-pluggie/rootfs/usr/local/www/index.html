How to install the certificate
  • Android (screen lock required): open Settings, search for certificate, tap Install a certificate → VPN & app user certificate and pick the file; then choose the certificate when Chrome or the Home Assistant app asks.
  • Home Assistant companion app on iOS (2026.9.1 or newer): the app asks for the certificate when the server requests it.
  • Desktop: import the file into the system keychain or your browser.
